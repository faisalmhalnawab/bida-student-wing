# BIDA Student Wing Website

Initial website platform for the BIDA Student Wing 2026–27 programme.

## Stack

- Next.js App Router
- TypeScript
- Plain CSS design system
- Intended deployment: Vercel
- Future integrations: live events/calendar, conference registration, research applications, email reminders and an internal content/admin workflow

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Current structure

- Home
- About
- Education
- Events
- Conference
- Research
- Opportunities
- News
- Resources
- Contact
- Privacy placeholder

The homepage is based on the approved/planned 2026–27 Student Wing programme structure. Dynamic systems and final approved organisational content will be connected in later build stages.
